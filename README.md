# 🌍 Monitor Kvaliteta Vazduha | Novi Pazar & Tutin

## 📖 O Projektu

Dobrodošli na **Monitor Kvaliteta Vazduha**, modernu platformu posvećenu praćenju zagađenja vazduha u regionu Sandžaka. Prvobitno razvijena za **Novi Pazar**, aplikacija je sada unapređena i proširena da uključi i **Tutin**.

Cilj ovog projekta je da građanima pruži tačne, transparentne i lako dostupne informacije o kvalitetu vazduha koji udišu, podižući svest o ekološkim izazovima u našoj zajednici.

---

## 🚀 Ključne Funkcionalnosti

- **📍 Monitoring Lokacija**: Trenutni podaci za **Novi Pazar** i **Tutin**.
- **📊 Real-time Podaci**: Prikaz koncentracije zagađujućih materija (PM2.5, PM10, itd.) u realnom vremenu.
- **📈 Istorijski Pregled**: Grafikoni i tabele sa istorijskim podacima za analizu trendova.
- **📱 Responsive Dizajn**: Optimizovano za prikaz na mobilnim telefonima, tabletima i desktop računarima.
- **⚡ Brzina i Performanse**: Izgrađeno na **Vite** platformi za trenutno učitavanje.

---

## 🛠️ Korišćene Tehnologije

Ovaj projekat koristi najsavremenije tehnologije za brz i pouzdan rad:

- **Frontend**: [React.js](https://reactjs.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Stilizacija**: Moderni CSS / Tailwind (ako je korišćen, ili custom CSS)
- **Podaci**: Integracija sa pouzdanim API servisima za merenje kvaliteta vazduha.

---

## ⚙️ Pokretanje Projekta

Želite da pokrenete projekat lokalno? Pratite sledeće korake:

1.  **Klonirajte repozitorijum:**
    ```bash
    git clone https://github.com/dzemilmanic/Monitor-kvaliteta-vazduha.git
    ```

2.  **Instalirajte zavisnosti:**
    ```bash
    npm install
    # ili
    yarn
    ```

3.  **Pokrenite razvojni server:**
    ```bash
    npm run dev
    # ili
    yarn dev
    ```

Aplikacija će biti dostupna na `http://localhost:5173`.
